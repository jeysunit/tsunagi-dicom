# Security / セキュリティ

> **医療機器としての承認・認証を受けていない。** 治験・研究・システムの試験の環境で使うためのもの。無償の OSS で、保証は無い。

## 脆弱性の報告 / Reporting a vulnerability

- GitHub の **Private vulnerability reporting** で知らせてほしい：このリポジトリの **Security** の頁 → **Report a vulnerability**。
  Please use GitHub **Private vulnerability reporting**: **Security** tab → **Report a vulnerability**.
- 公開の Issue・PR・議論に、脆弱性の中身を書かないでほしい。
  Please do not disclose details in public issues, pull requests, or discussions.
- 実の患者のデータ・施設の名前・秘密を報告に含めないでほしい（合成のデータで再現する）。
  Do not include real patient data, facility names, or secrets in a report; reproduce with synthetic data.
- 受けてから 7 日のうちに最初の返事をすることを目安にする（約束ではない）。直しの版を出してから、GitHub Security Advisories で公表する。
  We aim to reply within 7 days (best effort, not a commitment). Advisories are published after a fixed release is available.
