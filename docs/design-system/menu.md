# メニューの決まり

## 置き方

| 場所 | 置くもの | 置かないもの | 上限 |
|---|---|---|---|
| 上の帯（左から） | ナビの開閉・製品名・（空き）・患者 ID と受付番号の直接検索・つながりの状態・表示（明るい地／暗い地）・利用者のメニュー | 画面への道・画面の操作 | 右側 5 つまで |
| 左のナビ | 仕事の単位（名詞 1 語）。群は「業務」「接続」「管理」。現在地は `selected` の地＋左の線＋太字 | 操作・絞り込み・2 階層目 | 1 群 5 項目、全体 8 項目 |
| 見出しの行の右 | その画面の操作。主は右端、危険な操作は間をあけてその左 | 画面への道 | 主 1・副 3 |
| 利用者のメニュー | アカウント・ログアウト・（管理者の）役割の切り替え | 仕事の画面 | 5 項目 |

並べる順は、群の中では「毎日使う順」。「管理」は管理者の役割にだけ出し、役割に許されない項目は出さない（空の群は出さない）。項目名は名詞 1 語を基本とし、「〜の一覧」「〜管理」を付けない。動詞（作る・送る・開く）は画面の中のボタンにする。

## 3 製品のメニュー

| 製品 | 群 | 項目 |
|---|---|---|
| tsunagi-dicom | 業務／接続／管理 | 検査・受け取り／機器・保管の状態／利用者・ビューアの既定 |
| ris-emulator | 業務 | 予約・予約作成・一括作成 |
| dicom-test-generator | 業務／接続／管理 | ワークリスト・撮影・送信ジョブ／送り先／設定 |

名前は 3 製品の機能から付けた。同じ意味は同じ語にし（「検査」「予約」「送信」）、製品に無い機能の名前は持ち込まない。tsunagi の「機器」（画像サーバーに登録した相手）と DTG の「送り先」（DTG が送る相手）は別の機能なので、別の名前のままにする。

## 現状との差

tsunagi の今の上の帯は、検査一覧・受信一覧・接続先・ビューア設定・ユーザー管理・個人設定を並べている。上の表の「左のナビ」へ移すかどうかは、承認者の判断を待っている。決まるまでは今の上の帯のままにし、新しい画面の項目は上の帯の末尾に足さず、先にこの文書の PR で相談する。
