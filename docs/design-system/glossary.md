# 画面の言葉の決まり

3 製品（tsunagi-dicom・ris-emulator・dicom-test-generator）の画面に出す語と、語の使い分け。同じ意味には、製品をまたいで同じ語を使う。文の書き方（誤り・知らせ・窓）は [writing.md](writing.md) が決める。tsunagi-dicom の画面の言葉の表は `docs/spec.md` の 2.2 で、この文書と食い違うときは先に両方をそろえる。

## 規則

**画面の言葉は、医療の現場が PACS・RIS の画面で普通に使う語から選び、同じ意味には製品をまたいで同じ語を使う。** 例外は 2 件。(1) DICOM の属性名（StudyInstanceUID など）と設定の変数の名前は、そのまま出してよい。(2) シミュレーターの操作（予約・撮影・撮り直し・ルーチン・異常のデータ）は、各製品の仕様書の語を使う。

理由は、同じ意味の語が製品ごとに違うと（送信先／送り先、患者ID／患者 ID）、使う人が別の機能だと読むからである。

## 使い分けの決まり

1. **題・メニュー・列名・項目名・状態は体言。**
2. **ボタンも体言。** 動詞の形にしてよいのは次の 3 つだけ。慣用の「開く」「閉じる」「キャンセル」「ログイン」「ログアウト」。確かめの画面の実行（「送信する」「削除する」）。対になる選択と切り替え（「読み込む／読み込まない」「有効にする／無効にする」型）。
3. **状態の語の型。** 進行は「〜中」、結果は「〜完了」「〜失敗」、保留は「〜待ち」、管理者が記録に足す事実は「〜済み」。
4. **送る・受ける。** 画面の操作は「送信」だけで、「転送」「送る」は使わない。受けるのは「受信」。ファイルを入れるのは「インポート」、出すのは「エクスポート」。
5. **消す。** 「削除」だけ。「消去」「消す」は使わない。入力欄や絞り込みを空にするのは「クリア」。
6. **完了。** 処理の終わりは「完了」。「終了」は、アプリや窓を閉じる意味と混ざるので使わない。
7. **患者の氏名。** 一覧の列・詳細の項目は「氏名」。「患者名」「患者氏名」は使わない。
8. **ID。** 「患者ID」「ユーザーID」「要求ID」「受付番号」。「AEタイトル」も同じ。英字と日本語の間に空白を入れない。文の中の語（「Orthanc の設定」）は、これまでどおり空ける。
9. **「既定」は使わない。** いつも使う 1 件は「標準」、最初に入っている値は「初期設定」。
10. **ページは「ページ」。** 「頁」は画面（読み上げの名前を含む）に出さない。文書の地の文は、これまでの書き方のままにする。
11. **再送。** 操作の名前は「再送信」。結果が不明・失敗の行の横で、もう一度だけ試す操作は「もう一度送る」でもよい（体言の例外）。ボタンの並びや一覧の題では「再送信」を使う。どちらにするかは画面ごとに決め、同じ画面の中ではそろえる。

## 語の対照

| 意味 | 採る語 | 使わない語 |
|---|---|---|
| 患者の識別番号 | 患者ID | 患者 ID |
| 氏名 | 氏名 | 患者名・患者氏名 |
| 検査の名前（Study Description） | 検査名 | 検査の記述・検査記述 |
| 受付番号 | 受付番号 | — |
| 送信の相手 | 送信先 | 送り先 |
| 送信の操作 | 送信（実行は「送信する」） | 送る・転送 |
| 送信のやり直し | 再送信（行の横では「もう一度送る」でもよい） | 再送・送り直す |
| 送信の状態 | 送信待ち・送信中・送信完了・送信失敗・結果不明 | 待機中・送った・送れなかった |
| 接続の確かめ | 接続確認 | 確かめる・つながるか |
| 接続確認の結果 | 成功／失敗（列）、接続できました／接続できません（文） | つながった・つながらない |
| 接続先の項目 | 名称・AEタイトル・ホスト名・ポート番号（表の列では「ホスト」「ポート」「ホスト:ポート」も可） | 名前・AE タイトル・住所 |
| ワークリストを探す | ワークリスト検索・再検索 | ワークリストを取得・取得し直す |
| ファイルを入れる・出す | インポート・エクスポート | 取り込み・書き出し |
| 受信した | 新着・受信・受信日時 | 未読・受け取り |
| 絞り込みを空にする | 条件をクリア | 条件を消す |
| いつも使う 1 件 | 標準（標準のビューア） | 既定（既定のビューア） |
| 最初に入っている値 | 初期設定 | 既定 |
| ページ | ページ・前のページ・次のページ | 頁 |
| 窓の標準ボタン | キャンセル・閉じる | OK・はい・やめる |
| ユーザー | ユーザー・ユーザーID・表示名・役割 | 利用者 |
| ビューアの音引き | ビューア | ビューワ |

「検査日」の絞り込みの「今日・昨日・過去7日・今月・すべて・期間指定」と「詳細条件」、受信一覧の列「送信元 AE」は、今のまま。

## シミュレーターの語

予約・予約一覧・予約作成・一括作成・依頼科・名簿・装置・撮影・撮影して送る・追加撮影・撮り直し・ルーチン・異常のデータ・予定・実施中・取消・中止。これらは、各製品の仕様書の語を使う。

- 「実施中」「完了」「中止」は、検査の実施の状態（MPPS）の語と同じで、変えない。
- 「取消」は、文字に取り消し線を引かない（言葉そのものが誤りに見えるため）。

## 製品に取り入れない語

特定の製品の機能名・独自の概念（画像の管理の単位の名前、ゴミ箱、フラグなど）は、画面にも文書にも使わない。

## 機械で確かめる

使わない語は、画面に出ていないことを試験で見る（`tests/e2e/ui-feel.spec.ts` の `RETIRED_WORDS`）。語を決めたら、同じ PR でこの一覧にも足す。
