# 氏名の形の試験の一覧

DICOM の氏名（PatientName、VR は PN）を、このアプリが画面に出す2つの値に分ける規則と、その試験の形の一覧。
機械で読める同じ中身を [`tests/fixtures/patient-names.json`](../tests/fixtures/patient-names.json) に置く。**2つは同じ中身にそろえる**（片方を直したら、もう片方も直す）。

- **漢字の氏名**（`name`）：14px・太字・値の色（暗い地では白）で出す。漢字が無ければローマ字（またはローマ字の組に入っている値）を出す。
- **かなの氏名**（`kana`）：12px・ラベルの色（灰色）で出す。

## 規則

1. **組に分ける。** `=` で区切り、1つ目をローマ字（Alphabetic）、2つ目を漢字（Ideographic）、3つ目をかな（Phonetic）の組とする。足りない組は空。**4つ目以降の組は落とす。**
2. **成分に分ける。** 各組を `^` で区切り、**1つ目（姓）と2つ目（名）だけを使う**。3つ目以降（ミドルネーム・前置の敬称・後置の敬称）は落とす。日本の氏名は2つの成分で、落としても困らない。
3. **空白をそろえる。** 各成分の前後の空白（半角・全角・タブ）を落とし、成分の中の空白の並びは半角の空白1つにする。`^` でなく空白で区切った氏名（`山田 太郎`）は、そのまま1つの成分として扱う。
4. **半角カナを全角にそろえる。** 半角カナ（U+FF61〜U+FF9F）だけを全角にする（濁点・半濁点は1字にまとめる）。ほかの字（英数字・ひらがな・異体字）は変えない。ひらがなとカタカナは入れ替えない。
5. **成分をつなぐ。** 空の成分を除き、半角の空白1つでつなぐ。頭と末尾に空白を残さない。
6. **2つの値を決める。** 漢字の氏名＝漢字の組（空ならローマ字の組）。かなの氏名＝かなの組。**ローマ字の組の値を、かなの氏名へ移さない**（半角カナが入っていても推し量らない）。**かなの組を漢字の氏名へ繰り上げない**（漢字もローマ字も空なら、漢字の氏名は空のまま。画面では空であることが分かるように出す）。
7. **どんな入力でも例外にしない。** 読める字だけを出す。

検索（患者の氏名の漢字・かな・英字）は、この2つの値とローマ字の組の値を使う。ローマ字の組の値は画面に出さないときも、検索には使う。

## 一覧

## 来歴

- PN-01〜PN-23 は、画像サーバーの画面の設定（1本の正規表現の置換）で氏名を1行に整形したときの試験の 23 の形から取った。あちらは「1行の表示」の期待だったので、ここでは2つの値に分けて期待を書き直した。
- あちらで「1本の置換の限界」として崩れた見え方を固定していた3つ（PN-21 `^Taro`・PN-22 `=山田 太郎=やまだ たろう`・PN-23 `==やまだ^たろう`）は、ここでは正しく直る期待にした。
- PN-24〜PN-28 は、あちらで「例外にならないこと」だけを確かめていた形に、期待を足したもの。PN-29・PN-30 は、このアプリで足した形。
- 氏名はすべて架空のもの。
